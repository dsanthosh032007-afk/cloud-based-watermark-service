🎓 Project Specifications & Technical Architecture

College Mini-Project Showcase
1. HTML5 Canvas Pixel Modification

Unlike CSS overlays that merely display floating text, this system loads the image onto an offscreen <canvas>, calculates 2D matrix transformations (translation, rotation, alpha blending), and burns the watermark text directly into the raw pixel bitmap using ctx.fillText().

2. Lossless PNG Export

Exporting uses canvas.toDataURL('image/png'), which serializes the modified canvas frame into a base64 Data URI. The client dynamically generates a simulated anchor download link for 100% offline file generation with zero external server dependencies.
